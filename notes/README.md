# Notes

One file per week, plus `month-1.md` at the end. Write them in your own words —
short. The point is to catch what you actually learned while it's fresh, not to
fill in a form.

Each weekly template has the same four prompts:

1. **What I built** — a few lines, not a changelog.
2. **What confused me** — the thing that took longest to click.
3. **What I'd explain differently now** — teach it back to your past self.
4. **Open questions** — what you still can't answer.

These files are committed. Notebook outputs are not (nbstripout strips them), so
if a plot mattered, describe it or save it under `notes/` as an image.
